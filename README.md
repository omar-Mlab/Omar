# Material Lab – Operations Manager

تطبيق شخصي يشتغل على الموبايل (PWA). بيشتغل من غير نت، ومش محتاج اشتراك ولا سيرفر.
كل البيانات بتتحفظ على الموبايل نفسه في قاعدة بيانات اسمها IndexedDB.

---

## التثبيت أول مرة (مجاناً على GitHub Pages)

الأسهل تعمل الخطوات دي من كمبيوتر.

1. اعمل حساب مجاني على https://github.com
2. اعمل Repository جديد، مثلاً باسم `ml-ops`، وخليه **Public**. ده شرط عشان GitHub Pages يبقى مجاني.
   الكود بس هو اللي هيبقى ظاهر، أما **بياناتك فمش بتترفع خالص** وبتفضل على موبايلك.
3. داخل الـ Repository دوس **Add file ← Upload files**، واسحب كل محتويات الفولدر ده:
   `index.html`، `styles.css`، `sw.js`، `manifest.webmanifest`، وفولدر `js`، وفولدر `icons`.
   بعدها دوس **Commit changes**.
4. روح **Settings ← Pages**، واختار **Deploy from a branch**، وبعدها اختار `main` و `/ (root)`، ودوس **Save**.
5. استنى دقيقة أو اتنين، هيظهرلك لينك شكله كده: `https://USERNAME.github.io/ml-ops/`
6. افتح اللينك على الموبايل من **Chrome**، ومن قايمة ⋮ دوس **Install app** (أو "إضافة إلى الشاشة الرئيسية").

خلاص، التطبيق بقى على الشاشة الرئيسية بأيقونته، ويشتغل من غير نت.

### لو عايز ملف APK (اختياري)
افتح https://www.pwabuilder.com واكتب فيه لينك التطبيق، واختار **Android ← Download**.
هيديك ملف APK تثبته أو تحتفظ بيه.

## النسخ الاحتياطي (مهم جداً)

البيانات موجودة على الموبايل بس. لو الموبايل ضاع أو اتعمله فورمات، البيانات هتضيع معاه لو مفيش نسخة احتياطية.

- **كل أسبوع:** روح Data Management، ودوس **Share Backup**، وابعت الملف لـ Google Drive أو لنفسك على واتساب.
- التطبيق بياخد **Snapshot** داخلي كل يوم لوحده، وقبل أي Import. ده بيحميك من الأخطاء، لكنه مش بيحميك لو الموبايل نفسه ضاع.
- عشان ترجّع بياناتك على موبايل جديد: ثبت التطبيق، وبعدها **Data Management ← Import & Restore ← Restore Full Application Data**.

## التعديل في المستقبل

- الكود متقسم لملفات واضحة جوه فولدر `js`:

  | الملف | فيه إيه |
  |---|---|
  | `geo.js` | قسم Geotechnical وقواعد الـ Workflow |
  | `mat.js` | قسم Material |
  | `views.js` | الداشبورد، والبحث، و RV Tracking، والإحصائيات |
  | `exporters.js` | Excel و Word و PDF و CSV |
  | `datamgmt.js` | النسخ الاحتياطي والاستيراد |
  | `settings.js` | الإعدادات |
  | `store.js` | قاعدة البيانات والإعدادات الافتراضية |

- بعد أي تعديل: ارفع الملفات الجديدة مكان القديمة على GitHub، وغيّر رقم النسخة في أول سطر من `sw.js`
  (مثلاً من `mlops-v1.0.0` لـ `mlops-v1.0.1`). كده الموبايل هيحمّل النسخة الجديدة أول ما يفتح وهو متصل بالنت.
- **البيانات مش بتتمسح مع التحديث** طالما فضلت على نفس اللينك. ولو التعديل كبير، خد Backup قبله للاحتياط.
